Why it's fast

Tiny native shell

~2 MB C++ app. No Electron, no bundled engine. On Windows it renders with Chromium via Microsoft Edge WebView2; on Linux with the system WebKitGTK engine. Same ad blocker, same pages, same settings.

Linux too

A native GTK4 + libadwaita build, 800 KB. Install the .deb on Ubuntu or Debian, or unpack the tarball. Sync and passwords are still Windows-only for now.

Ad blocker that keeps itself current

Network-level host and URL rules plus cosmetic filters, refreshed every day from public block lists and our own curated rules. A live counter shows what was blocked.

YouTube, Spotify, Twitch

In-stream YouTube ads are skipped or fast-forwarded muted, the "ad blockers are not allowed" dialog is dismissed, and Spotify and Twitch ads play silently.

Smart address bar

Ranked suggestions from your bookmarks and history, plus popular sites and pages other Light Browser users visit, grouped by kind: video, music, dev, news and more. Click or arrow-select.

Tab sleeping and deep sleep

Background tabs suspend after 30 seconds and unload after 10 minutes idle. Minimize for a few minutes and the whole engine shuts down, leaving a few MB.

Import everything

Bookmarks, history, saved logins and autofill from Chrome, Edge, Brave, Opera, Vivaldi and Firefox. Firefox passwords decrypt through its own key store.

Encrypted sync

Bookmarks and passwords sync across devices. Encrypted on your PC with your passphrase. The server only ever sees ciphertext.

Password manager

Saved logins in one place: search, reveal, copy, delete, and generate strong passwords. Autofill signs you in.

Resource monitor

See live CPU, memory, GPU and GPU-memory use with a per-process breakdown, and cap memory so background tabs suspend when you go over.

Light and dark

Follows your Windows theme, or pin it to light or dark. The whole window follows, title bar included.

Developer ready

Full Chromium DevTools with F12 or right-click → Inspect. Google search straight from the address bar. Cloudflare DNS over HTTPS by default.

Tabs that stay out of your way

Pin tabs, color them into groups, and with ten or more tabs the strip turns into a vertical list. Hover a tab to see its RAM; a red dot marks heavy tabs and one click frees them.

Picks up where you left off

Your last session comes back as sleeping placeholders. Only the tab you look at loads, so startup costs one page, not twenty.

Search your way

Google, Bing, DuckDuckGo, Brave, Yandex, Ecosia or your own engine. Keywords jump straight to a site: yt lofi, w rust, gh webview2.

Find, download, permissions

Find in page with a live match count, a download manager with pause and resume, and site permissions you decide once and can revoke in Settings.

Settings page and first-run wizard

Every option on one page (Ctrl+,). A four-step welcome picks theme, a RAM limit sized to your PC, search engine and import.

Survives crashes

A dead page shows a reload button instead of a blank tab, a hung one is marked, and if the engine itself dies the browser rebuilds it and reloads your tab.

Auto-update

New versions install silently from GitHub Releases after a SHA-256 check. See the release history.

Security and privacy

  • Auto-update. The browser checks GitHub Releases on startup and from its About page. Every update is verified with SHA-256 before it installs.
  • End-to-end encryption. Synced data uses AES-256-GCM under a key derived from your passphrase (PBKDF2-SHA256, 210k rounds). Forget the passphrase and it cannot be recovered. That is the point.
  • Shared suggestions, no tracking. The address bar's shared site pool stores only public site addresses and page titles with visit counts. No user ids, no query strings, no mail, banking, messaging or account pages. You can turn sharing off in settings.
  • Linux. The .deb and tarball need no signing. Install with sudo apt install ./lightbrowser_*.deb; the app checks GitHub for new versions and shows a notice.
  • Scanned on VirusTotal. Each download card links to the VirusTotal report of that exact file (matched by SHA-256, 70+ antivirus engines). A "Unknown publisher" note from Windows only means the installer is not code-signed yet; the scan result is what tells you it is clean.
  • Verify your download. Each release ships LightBrowser-Setup.exe.sha256 and .sha256 sidecars for the Linux files. Latest: checksum file.
(Get-FileHash LightBrowser-Setup.exe -Algorithm SHA256).Hash.ToLower()
