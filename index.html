A ~2 MB native Windows browser on the Chromium engine already inside Windows 11. Built-in ad blocker, tab sleeping, end-to-end-encrypted sync, one-click import from other browsers.

Why it's fast

Tiny native shell

~2 MB C++ Win32 app. No Electron, no bundled engine. Rendering is Chromium via Microsoft Edge WebView2, which Windows 11 already ships.

Ad blocker built in

Network-level host and URL rules plus cosmetic filters. Every request passes through it. A live counter shows what was blocked.

Tab sleeping

Background tabs drop to a low memory target and get suspended after 30 seconds idle. Near-zero CPU until you click them.

Import everything

Bookmarks, history and saved logins from Chrome, Edge, Brave, Opera, Vivaldi and Firefox, in one click.

Encrypted sync

Bookmarks and passwords sync across devices. Encrypted on your PC with your passphrase. The server only ever sees ciphertext.

Developer ready

Full Chromium DevTools with F12 or right-click → Inspect. Google search straight from the address bar.

Security and updates

  • Auto-update. The browser checks GitHub Releases on startup and from its About page. Every update is verified with SHA-256 before it installs.
  • End-to-end encryption. Synced data uses AES-256-GCM under a key derived from your passphrase (PBKDF2-SHA256, 210k rounds). Forget the passphrase and it cannot be recovered. That is the point.
  • Verify your download. Each release ships LightBrowser-Setup.exe.sha256. Latest: checksum file.
(Get-FileHash LightBrowser-Setup.exe -Algorithm SHA256).Hash.ToLower()
Get-Content LightBrowser-Setup.exe.sha256
