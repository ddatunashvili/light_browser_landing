Releases and updates

Light Browser checks for updates on startup and installs them silently after a SHA-256 check. This page lists every version with its notes and downloads.

How updating works

  • Automatic. On startup (at most every 6 hours) the browser reads the latest release from GitHub. If it's newer, the installer downloads, its checksum is verified, and it installs and relaunches.
  • Manual. Open the ⋮ menu → About → Check for updates, or download any version below and run it over the existing install.
  • Ad filters update separately, once a day, without a new browser version. ⋮ → Update ad filters now forces a refresh.
  • Portable builds do not self-update; download the new LightBrowser.exe and replace the old one.
