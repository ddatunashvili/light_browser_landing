~2 MB C++ აპლიკაცია. არც Electron, არც ჩაშენებული ძრავი. Windows-ზე რენდერინგს Chromium აკეთებს Microsoft Edge WebView2-ის მეშვეობით, Linux-ზე — სისტემური WebKitGTK ძრავი. იგივე რეკლამის ბლოკერი, იგივე გვერდები, იგივე პარამეტრები.

Linux-ზეც

ნატიური GTK4 + libadwaita ვერსია, 800 KB. დააყენეთ .deb Ubuntu-ზე ან Debian-ზე, ან გახსენით არქივი. სინქრონიზაცია და პაროლები ჯერჯერობით მხოლოდ Windows-ზეა.

რეკლამის ბლოკერი, რომელიც თავად ახლდება

ქსელის დონის ჰოსტისა და URL-ის წესები პლუს კოსმეტიკური ფილტრები, რომლებიც ყოველდღიურად ახლდება საჯარო ბლოკ-სიებიდან და ჩვენი შერჩეული წესებიდან. მრიცხველი პირდაპირ აჩვენებს, რა დაიბლოკა.

YouTube, Spotify, Twitch

YouTube-ის ვიდეოში ჩაშენებული რეკლამები გამოიტოვება ან ხმის გარეშე გადაიხვევა, „რეკლამის ბლოკერები აკრძალულია“ ფანჯარა იხურება, Spotify-სა და Twitch-ის რეკლამები კი უხმოდ უკრავს.

ჭკვიანი მისამართების ველი

დახარისხებული შეთავაზებები თქვენი სანიშნეებიდან და ისტორიიდან, პლუს პოპულარული საიტები და გვერდები, რომლებსაც Light Browser-ის სხვა მომხმარებლები სტუმრობენ — დაჯგუფებული ტიპის მიხედვით: ვიდეო, მუსიკა, დეველოპმენტი, სიახლეები და სხვა. აირჩიეთ დაწკაპუნებით ან ისრებით.

ტაბების დაძინება და ღრმა ძილი

ფონური ტაბები 30 წამში ჩერდება და 10 წუთი უმოქმედობის შემდეგ მეხსიერებიდან იტვირთება. ჩაკეცეთ ფანჯარა რამდენიმე წუთით და მთელი ძრავი ითიშება — რჩება მხოლოდ რამდენიმე MB.

ყველაფრის იმპორტი

სანიშნეები, ისტორია, შენახული პაროლები და ავტოშევსება Chrome, Edge, Brave, Opera, Vivaldi და Firefox-იდან. Firefox-ის პაროლები მისივე გასაღებების საცავით იშიფრება.

დაშიფრული სინქრონიზაცია

სანიშნეები და პაროლები მოწყობილობებს შორის სინქრონდება. იშიფრება თქვენს კომპიუტერზე თქვენივე საიდუმლო ფრაზით. სერვერი მხოლოდ დაშიფრულ მონაცემებს ხედავს.

პაროლების მენეჯერი

შენახული პაროლები ერთ ადგილას: ძებნა, ჩვენება, კოპირება, წაშლა და ძლიერი პაროლების გენერაცია. ავტოშევსება თავად შეგიყვანთ.

რესურსების მონიტორი

ნახეთ CPU-ს, მეხსიერების, GPU-სა და GPU-მეხსიერების გამოყენება პროცესების მიხედვით და დააწესეთ მეხსიერების ლიმიტი, რომლის გადაჭარბებისას ფონური ტაბები ჩერდება.

ღია და მუქი თემა

მიჰყვება Windows-ის თემას, ან დააფიქსირეთ ღია ან მუქი. მთელი ფანჯარა იცვლება, სათაურის ზოლის ჩათვლით.

დეველოპერებისთვის

სრული Chromium DevTools F12-ით ან მარჯვენა დაწკაპუნებით → Inspect. Google-ის ძებნა პირდაპირ მისამართების ველიდან. Cloudflare DNS over HTTPS ნაგულისხმევად.

ტაბები, რომლებიც ხელს არ გიშლის

ჩაამაგრეთ ტაბები, დააჯგუფეთ ფერებით, ათი და მეტი ტაბისას კი ზოლი ვერტიკალურ სიად იქცევა. გადაატარეთ მაუსი ტაბს და ნახავთ მის RAM-ს; წითელი წერტილი მძიმე ტაბს აღნიშნავს და ერთი დაწკაპუნებით ათავისუფლებს.

იქიდან აგრძელებს, სადაც გაჩერდით

ბოლო სესია მძინარე ჩანაცვლებებად ბრუნდება. მხოლოდ ის ტაბი იტვირთება, რომელსაც უყურებთ — გაშვება ერთი გვერდი ღირს, არა ოცი.

ძებნა თქვენებურად

Google, Bing, DuckDuckGo, Brave, Yandex, Ecosia ან საკუთარი ძრავი. საკვანძო სიტყვები პირდაპირ საიტზე გადაგიყვანთ: yt lofi, w rust, ge ამინდი.

ძებნა გვერდზე, ჩამოტვირთვები, ნებართვები

ძებნა გვერდზე დამთხვევების მრიცხველით, ჩამოტვირთვების მენეჯერი პაუზითა და გაგრძელებით, საიტების ნებართვები, რომლებსაც ერთხელ წყვეტთ და პარამეტრებში აუქმებთ.

პარამეტრების გვერდი და პირველი გაშვების ოსტატი

ყველა პარამეტრი ერთ გვერდზე (Ctrl+,). ოთხსაფეხურიანი მისალმება ირჩევს თემას, თქვენი კომპიუტერისთვის მორგებულ RAM ლიმიტს, საძიებო სისტემასა და იმპორტს.

უძლებს ავარიებს

მკვდარი გვერდი ცარიელი ტაბის ნაცვლად გადატვირთვის ღილაკს აჩვენებს, გაჭედილი მონიშნულია, ძრავის დაცემისას კი ბრაუზერი მას თავად აღადგენს და ტაბს ხელახლა ტვირთავს.

ავტომატური განახლება

ახალი ვერსიები GitHub Releases-იდან ჩუმად ინსტალირდება SHA-256 შემოწმების შემდეგ. იხილეთ ვერსიების ისტორია.

უსაფრთხოება და კონფიდენციალურობა

  • ავტომატური განახლება. ბრაუზერი GitHub Releases-ს ამოწმებს გაშვებისას და About გვერდიდან. ყოველი განახლება ინსტალაციამდე SHA-256-ით მოწმდება.
  • ბოლოდან ბოლომდე დაშიფვრა. სინქრონიზებული მონაცემები AES-256-GCM-ით იშიფრება გასაღებით, რომელიც თქვენი საიდუმლო ფრაზიდან იწარმოება (PBKDF2-SHA256, 210 ათასი იტერაცია). თუ ფრაზა დაგავიწყდათ, აღდგენა შეუძლებელია. სწორედ ეს არის მიზანი.
  • საერთო შეთავაზებები, თვალთვალის გარეშე. მისამართების ველის საერთო საიტების ბაზა ინახავს მხოლოდ საჯარო საიტების მისამართებსა და გვერდების სათაურებს ვიზიტების რაოდენობით. არანაირი მომხმარებლის ID, არანაირი query string, არანაირი ფოსტის, ბანკის, მესენჯერის ან ანგარიშის გვერდი. გაზიარება პარამეტრებში ითიშება.
  • Linux. .deb-სა და არქივს ხელმოწერა არ სჭირდება. დააყენეთ sudo apt install ./lightbrowser_*.deb-ით; აპლიკაცია GitHub-ზე ამოწმებს ახალ ვერსიებს და შეტყობინებას აჩვენებს.
  • შეამოწმეთ ჩამოტვირთული ფაილი. ყოველ ვერსიას მოყვება LightBrowser-Setup.exe.sha256 და .sha256 ფაილები Linux-ის ფაილებისთვისაც. უახლესი: checksum ფაილი.
